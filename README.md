# Mareyki Cocina Peruana

Site estático em HTML, CSS e JavaScript.

## Abrir e editar
Extraia o ZIP e abra a pasta no VS Code. Abra index.html com Live Server.
O projeto inclui index.html, cardapio.html, style.css, script.js, cardapio-animation.js e assets/imagens.

## Hospedar
Os arquivos estão na raiz do ZIP. Para upload direto no Cloudflare Pages, envie o ZIP.
Para integração GitHub, use preset None, sem comando de build e diretório de saída na raiz.
Nenhum backend é necessário. As fontes usam Google Fonts com fallback local.

## Conteúdo
Endereço, Instagram e iFood foram fornecidos pelo solicitante.
O cardápio contém 32 itens com os preços e descrições disponíveis nas capturas do iFood.
As fotografias do cardápio foram fornecidas pelo solicitante. As imagens são carregadas dos links públicos do Supabase fornecidos pelo solicitante e dependem de acesso à internet. As cópias locais estão incluídas em assets/imagens. A imagem principal do ceviche e as imagens da seção Sabores do Peru foram geradas para o projeto.
Os horários, as descrições ausentes e a atualização de preços ainda devem ser conferidos com o restaurante.
A animação dos dentes roda no título do cardápio e respeita movimento reduzido.
